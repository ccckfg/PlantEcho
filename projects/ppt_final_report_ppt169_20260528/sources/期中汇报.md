## 项目题目

**基于 ESP32 与大语言模型的智能植物陪伴与养护系统**

这个项目面向喜欢在家养植物的用户，想法挺简单——用传感器采集植物周围的环境数据，结合大语言模型，让植物"会说话"，以拟人化的方式提醒用户浇水、晒太阳、避光，让养植物这件事不只是定期打理，而是多一点陪伴感。

---

## 整体架构

![智能植物陪伴与养护系统架构图](ChatGPT%20Image%20May%2015%2C%202026%2C%2010_26_41%20PM.png)

整体采用「硬件感知 + Node.js 服务端（大语言模型中间件） + 跨平台客户端」的架构。

**硬件端**：ESP32 作为核心，接土壤湿度、温湿度、光照传感器，通过 MQTT 或 HTTP 把数据推到服务端。

**服务端**：基于 Node.js，负责接收设备数据、管理用户信息、植物档案和对话记录，同时作为 LLM 中间件，处理植物角色设定、会话管理、长期记忆、RAG 检索和提醒策略。对外提供兼容 OpenAI Chat Completion 格式的接口，这样官方客户端和第三方支持 OpenAI API 的客户端都可以直接接入。

**客户端**：基于 Tauri v2 开发，同时支持 Windows、Android、macOS 三端。用户可以创建植物档案、上传植物照片、查看传感器数据、接收养护提醒，并直接跟植物聊天。

**功能层面**：系统结合植物习性知识库、实时传感器数据和天气 API，针对不同植物生成浇水、光照等养护建议；用户长时间没打开 App 时，植物也会主动"开口"提醒。

## 遇到的问题

**硬件这块最陌生。** ESP32 怎么稳定读传感器数据、怎么处理误差、怎么可靠地把数据推上来，都需要边学边做。

**模块太多，不好一下铺开。** ESP32、Node.js 服务端、Tauri 客户端、LLM 调用、RAG、天气 API、消息推送……全部同时搞肯定乱，得想清楚先做哪块、怎么拆。

**养护建议需要靠谱。** 不同植物对水分、光照的需求差很多，不能让系统给出明显不合理的建议。后续需要整理一份植物习性资料，配合 RAG 和 Prompt 设计来保证建议质量。

整体思路是先跑通一个最小版本，再慢慢往上加功能。

**第一步**：学 ESP32 基础开发，把传感器接好，能读出土壤湿度、温湿度、光照数据。

**第二步**：搭 Node.js 服务端基础接口，让 ESP32 能把数据传上来并存起来。

**第三步**：开发客户端原型，基于 Tauri v2，同步开发 Windows、Android、macOS 三端，先把植物档案创建、状态查看、基础对话做出来。

**第四步**：接入大语言模型 API，让植物能结合传感器数据和知识库，用拟人化的语气跟用户说话，给出养护建议。

**后续**：天气 API、长期记忆、RAG 检索、消息推送、主动提醒……一步步补上，把系统从监测工具做成真正有陪伴感的东西。
